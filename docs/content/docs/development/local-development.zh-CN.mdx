# 本地开发

当前主应用以 `web/` 前端为主，AI 请求由浏览器前台直连用户自己的 OpenAI 兼容接口。

## 1. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

## 2. 配置模型

打开 `http://localhost:3000`。本分支登录走顶栏头像（同源 `/new-api`），不要再配 MaaS `/prod-api` 加密登录。普通用户登录后默认渠道会写入控制台 `auto` 密钥，Base URL 是 `/gw`；渠道里的 Base URL / API Key 表单项只给 `admin` 看。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
